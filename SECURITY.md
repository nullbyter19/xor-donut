# Security policy

## Supported versions

Only the latest commit on `main` is supported.

## Reporting a vulnerability

Please do not open a public issue for security problems. Use the repository's
**Security** tab and select **Report a vulnerability** (GitHub private
advisory). Include reproduction steps, affected files and the impact you
observed.

You can expect an initial response within seven days. Once the issue is
confirmed, a fix and an advisory will be prepared and you will be credited
unless you ask otherwise.

## Scope

This project is published for authorized security testing, research and
education. Vulnerabilities in the project itself are in scope. Findings about
third-party products must be reported to the respective vendor.

## Safe harbor

Good-faith research on your own deployments of this project is welcome. Do not
test against systems you do not own or have written permission to test.
